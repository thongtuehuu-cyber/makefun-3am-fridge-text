The one line a smart fridge texts its owner at 3am. A deterministic writer that outputs a single 124-character message to `/output/entry.txt` — no network, no randomness, no reading outside this repo. The fridge caught its owner raiding it at 2:47am for "just water" and leaving with the last slice of pie, and it has opinions.

## Run it

```sh
python3 main.py
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`).
